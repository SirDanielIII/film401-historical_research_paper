# Beyond the Green Screen

**Petro Vlahos and the Evolution of Special Effects** · FILM 401

A continuous historical research exhibit with two offline demonstrations and five optional narration recordings. Research is substantially longer than the presentation. The formal 800-word paper remains a separate requirement unless the instructor approves a creative equivalent.

## Run

```sh
npm install
npm run dev
```

Open the local URL printed by Vite, normally `http://localhost:5173/`. On Windows PowerShell, use `npm.cmd` if execution policy prevents `npm.ps1` from running.

```sh
npm run build
npm run preview
npm run lint
npm test
```

Build output is `dist/`. Its relative asset base supports `/projects/petro-vlahos/` and root deployment. Serve the build through a web server; opening the HTML with `file://` is unsupported. No production dependencies were added.

## Explore or present

The single chapter menu follows Introduction → Biography → Before Vlahos → Colour Difference → Sodium Vapour → Ultimatte & Legacy → References. Further Questions and the glossary appear before the bibliography.

Main historical research is visible by default. Advanced technical explanations and the classroom questions are optional disclosures. Start Presentation uses the same sections, with detailed research temporarily tucked away and a compact persistent player. Each section can restore its research while presenting.

The player provides chapter selection, previous/next, play/pause, seeking, elapsed/total duration, speed, and transcript. No audio autoplays. Only one recording can play at a time. Missing audio leaves the transcript available. Arrow keys change narration chapters while the player is open; Space plays/pauses outside native controls; Escape closes the player and leaves presentation mode. Inputs and the horizontally scrollable phone optics diagram retain their own keyboard controls.

## Content and recordings

- `src/data/chapters.ts`: detailed research blocks, with citations.
- `src/data/context.ts`: expanded political/industrial context, earlier methods, and legacy.
- `src/App.tsx`: continuous sequence, biographies, visual summaries and case studies.
- `src/data/questions.json`: all 24 dossier questions, grouped into seven topics.
- `src/data/sources.ts`: all 13 original bibliography sources plus identified supplementary sources.
- `src/data/narration/*.txt`: five editable scripts, also used as transcripts.
- `public/recording-script.txt`: printable export regenerated by `npm run media`.

The scripts contain **666 spoken words**: about **4:45 at 140 wpm**, plus time for pauses and demonstrations. Actual timing depends on rehearsal. Record your own voice; no generated narration is included.

Place your recordings in `public/media/audio/`:

1. `01-introduction.mp3`
2. `02-biography.mp3`
3. `03-colour-difference.mp3`
4. `04-sodium-vapour.mp3`
5. `05-legacy.mp3`

Run `npm run media` and restart dev or rebuild. M4A, WAV and OGG are also detected. Chapter 3 covers both earlier matting and colour difference; a player link takes the presenter onward to the demo. Playback never advances automatically.

## Brand and assets

The supplied `src.zip` informed the palette, two themes, Berlin Sans typography, rounded photographs, borders, spacing, hover states and responsive conventions. Long prose follows the reference site's guide article convention of readable system typography. `src/styles/theme.ts` is the small standalone equivalent of its theme tokens.

All three genuine TrueType assets are present: `public/fonts/BRLNSR.TTF`, `BRLNSD.TTF`, `BRLNSB.TTF`. Font metadata and browser loading were checked. Nothing was downloaded as a replacement font.

`src/data/media-manifest.json` centralizes the 17 local images, captions, source links, authors, dimensions, rights notes and section associations. Fifteen are historical photographs, film comparisons or patent facsimiles; two are modern demonstration photographs. Images occupy about 1.9 MB in total. External hotlinks are not used in the exhibit.

Film and archival images are educational reference copies with public-hosting uncertainty. Source attribution does not itself give permission. The on-page media register and manifest record the distinction. Set an entry to `enabled: false` to hide it and exclude its copied image from the **standalone production build**. Review replacements/permissions before public deployment. Do not upload the repository or `public/` as the deployment; publish the built `dist/`.

See [ASSETS_NEEDED.md](ASSETS_NEEDED.md) for the short prioritized request list and [INTEGRATION.md](INTEGRATION.md) for the host ThemeProvider adapter, lazy route, asset paths and release considerations.

## Demonstrations

**Colour difference:** actual RGB/grayscale views of a local green-screen photograph; an estimated matte; a poor-versus-improved key comparison; final composite. The original illustrated model remains selectable for fine-edge/glass examples. The software key is deliberately simple and imperfect. It does not claim to implement Vlahos's photochemical patent. Replace the photograph and room background through the manifest; the photographic algorithm currently assumes green.

**Sodium vapour:** a local SVG model of narrowband backing illumination, coated optical separation, colour and monochrome records, and later photographic printing. Four steps, stage view and final composite remain interactive. Historical camera photographs and an original patent drawing sit beside the explanation. A yellow RGB photograph is not presented as genuine spectral capture.

## Validation

`npm test` checks reference integrity, all 24 sourced answers, narration length, distinct research, local media records/files, TrueType signatures, and unloaded audio timing. There is no maximum research word count.

Browser functions in `tests/` can be run using Chrome DevTools `evaluate_script --sourcePath`:

- `browser-check.js`: continuous content, navigation, fonts/images, modes, demo pixel output, comparison controls, transcripts and missing audio.
- `layout-check.js`: section and viewport overflow checks.
- `browser-audio-check.js`: playback, pause, seek, rate, single-player cleanup and missing chapters, using temporary test fixtures.

`npm run test:audio:prepare` creates two quiet **test tones**, never narration, and refuses to overwrite existing recordings. After browser QA run `npm run test:audio:clean` and rebuild. Do not deploy fixtures.

Current validation and assignment coverage are recorded in `research/VERIFICATION.md` and `research/CONTENT-COVERAGE.md`. Screenshots and raw QA results are local in ignored `artifacts/`. Original DOCX files and `src.zip` remain untouched; the full DOCX text and original hyperlink targets are retained in `research/`.
